## Phase A で決めた解釈

- お手本は許容帯（幅 = ±ピッチ許容、既定 30 cent）。帯を外れて ±50 cent まではアンバー、超えたらコーラル赤
- 信頼度 0.5 未満の点、および 15 ms 以上の欠落は線を切る（嘘でつながない）
- 自分の線は再生ヘッドまで（歌ったところだけ）
- テンポ / キーの数値は右ラックに集約
- モニターリバーブはモニターミックスの 1 チャンネル（「耳のみ」、M/S なし）
- 録音中の赤はキャンバスの縁・タリー・再生ヘッド・録音中の区間だけ（画面全体は赤くしない）
- 起動時は停止状態（0:39）。`--play` で動く
- ウィンドウ最小 1280x800
- 再生・録音の時計は見た目だけ（音声デバイスは開かない）

## オフボの再生（B2）

曲を開いていて出力デバイスがあるとき、再生・シーク・ループは鳴っている音そのもの（再生ヘッドは音の位置から取る）。曲を開いていない（デモ表示）・出力デバイスが無いときは、従来どおり見た目の時計で動く。

| 操作 | 結果 |
|---|---|
| 再生キー / Space | オフボを再生・一時停止。曲の終わりで止まる（終わりで押すと頭から） |
| 停止キー | 止める（位置はそのまま） |
| 頭へキー | 頭へ（ループ中は範囲の頭へ） |
| 全体表示・レーンをクリック | その位置へ（再生中でも途切れずに飛ぶ） |
| レーンをドラッグ / `[` `]` | 範囲。ループ（`L`）が点いていれば範囲の終わりで頭へ戻る（すき間・重なりなし） |
| モニターの「オフボ」フェーダー | 音量（75 = 0 dB、100 = +6 dB、0 = 無音。急に変えず 20 ms でなめらかに） |
| 「オフボ」の M | ミュート |

| ステータスバー（右端） | 意味 |
|---|---|
| OUTPUT デバイス名 / kHz / バッファ | 開いている出力デバイス。曲を開くと SR を曲に合わせる |
| SR 変換して再生中 | デバイスが曲の SR に切り替えられないとき（試聴用に変換。DESIGN 13） |
| 出力デバイスを開けません：理由 | デバイスが無い・使われている等。画面はそのまま使える |
| UI MOCK | `-DVOICEBOOTH_UI_MOCK=ON` のビルド（音声デバイスを一切開かない） |

まだ無いもの：テンポ / キー（B11）、クリック・カウントイン、ほかのフェーダー（お手本・自分・リバーブ）、モニター・録音（B4〜）。

## デバイスと入力メーター（B3）

起動すると前回のデバイス（アプリ設定の `audioDevice`。戻せなければ既定）を開く。入力は 1 ch だけ（モノラル、既定 L）を開いてメーターに通す。入力の音は出力に流さない（モニターは B4）、録らない（B5）。

| 場所 | 表示 |
|---|---|
| ラックの INPUT | 機器名 — チャンネル（2 ch の機器は L / R）、ドライバとバッファ、LED メーター（ピーク・RMS・ホールド・クリップ）、PEAK / RMS の数値、適正 / 調整、LATENCY「… ms / … smp（申告値）」 |
| ステータスバー | 小さいメーター（クリックでクリップを消す）、ピーク dBFS、LATENCY「… ms（申告値）」、DRIVER |
| トップバーの入力デバイス | 機器名 — チャンネル。入力が無ければ「入力なし」（警告色） |
| 入力セットアップ 1 デバイス | 入力 / 出力の一覧（クリックで切り替え、多ければホイールで送る。名前が Bluetooth らしければ「遅延が大きい」）、DRIVER（2 種以上ならプルダウン）、CHANNEL（L / R など。1 ch の機器はモノラル）、SAMPLE RATE（いま / 対応）、BUFFER（プロはプルダウン、ほかは自動）、LATENCY（デバイスの申告値。実測ではないと明記）、MIC ACCESS（入力の状態）、切り替えに失敗した理由 |
| 入力セットアップ 2 レベル | 実メーター。判定はホールド（1.5 秒の最大）で：-3 dBFS 超「大きすぎます」/ -20 dBFS 未満「小さすぎます」/ それ以外 OK |
| 入力セットアップ 3 レイテンシ | 「REPORTED BY DEVICE」としてデバイスの申告値（入力 + 出力）。測定キーは押せない（実測と録音位置の補正は B6） |

メーター：ピークは下がる時 20 dB/秒、ホールドは 1.5 秒保ってから 20 dB/秒、RMS は直近 300 ms、クリップは -0.1 dBFS 以上が 1 サンプルでもあれば点灯し、クリックするまで残る。表示は 30 Hz。

| ステータスバー（右端の札） | 意味 |
|---|---|
| マイクの許可がありません | Mac で許可されていない。入力セットアップの「次へ」が押せない（DESIGN 13）。システム設定で許可してから開き直す |
| マイクの許可を確認中 | Mac の許可ダイアログに答え待ち |
| 入力デバイスがありません | 入力の機器が無い |
| 入力を開けません | 開けない（使用中・拒否など）、または選んだ機器から音が来ない。理由は入力セットアップに出る |
| 入力が完全に無音 | 開いているのに 0 ちょうどが 2 秒続く（OS のマイクの許可・ミュート・ケーブルの疑い） |
| 入力が止まりました ＋「オーディオデバイスが応答しません…」 | 開いていたデバイスが止まった（抜けた・サウンドサーバーが落ちた）。入力セットアップを開くと開き直す |

デバイスが外れた・止まった時は、再生を止めて「オーディオデバイスが外れました…」と知らせる（DESIGN 13「デバイス抜け：停止して再選択」）。

## 自分の声のモニター（B4）

入力（1 ch）を出力の L / R に同じ量で返す。曲が止まっていても入力があれば鳴る。録音はまだしない（B5）。

| 場所 | 動き |
|---|---|
| モニターの「自分」フェーダー | 返す量（75 = 0 dB、オフボと同じ目盛り）。横のメーターは耳に返っている量（入力のピーク＋フェーダー、-48〜0 dBFS） |
| 「自分」の M | 返さない。インターフェースのダイレクトモニターで聞く時はこちら |
| モニターの「リバーブ」フェーダー | 耳だけに掛けるリバーブ（小さめの部屋）の量。送りは「自分」のフェーダーの後。録音には入らない（DESIGN 4.7 / 14） |
| モニターの下の知らせ（スピーカー） | 出力の機器名がスピーカーらしい（`looksLikeSpeakers`：speaker / スピーカー / 扬声器 / 揚聲器 / 스피커、ヘッドホンの語があれば除く）時、その機器に替わった最初だけ「自分」を M にして理由を出す（アンバー）。M を外して鳴らしている間は「ハウリングに注意」（コーラル） |
| モニターの下の知らせ（遅れ） | 入力が開いていて「自分」を返している時、デバイスの申告の往復が 40 ms を超えたら「約 N ms 遅れて聞こえます。バッファを小さく／インターフェースで直接」（アンバー）。実測は B6 |

音の決まり：「自分」の分（リバーブ込み）は ±1 に収める（ハウリング・大声で耳を傷めないための最後の砦。オフボには掛けない）。音量・ミュート・リバーブ量は 20〜50 ms でなめらかに変わる。

![](screenshots/b4-monitor.png)

確認（Linux、PulseAudio の仮想デバイス 2 つ：入力用・出力用。入力に 441 Hz -12 dBFS を流して出力を録る）：
- 「自分」0 dB・リバーブ 0：出力 L / R とも -12.00 dBFS、止めた後は何も残らない
- 既定（「自分」64 = -2.8 dB、リバーブ 25）：-14.8 dBFS 前後、止めた後に左右で違う残響（50 ms 後 -34 dBFS → 1 秒後 -75 dBFS）
- 「自分」の M：出力は無音、遅れの知らせも消える

## 通し録音と書き出し（B5）

曲を開いていて入力がある時、REC（R）で再生と同時に、アームしたトラック（● が点いたトラック）へ録る。

| 操作・場所 | 動き |
|---|---|
| REC / R | 録音を始める（止まっていれば今の位置から再生）。録音中はループしない。もう一度 REC / 停止 / Space で止める |
| 録れない時 | 何もせず理由を知らせる：曲を開いていない / 入力（マイク）が使えない / アームしたトラックが無い / 機器を曲と同じ SR で開けない |
| 録り終わり | 「Main の take1 を録りました（0:00.000 - 0:04.021）」。割れがあれば「割れ（クリップ）があります」。練習録音は「納品には入りません」 |
| 曲の終わり・デバイスが止まった | そこまでをテイクとして閉じる（録った声は捨てない） |

## 録音形式（SR・ビット数。2026-10-01）

入力セットアップ 1 デバイスの「REC FORMAT」行。標準・プロで選べる。簡単は「自動（曲に合わせる・24bit）」。選んだ形式はアプリ設定に保存。

| 場所 | 動き |
|---|---|
| SR のプルダウン | 「曲に合わせる（48 kHz）」と、この機器で録れる値（44.1 / 48 / 88.2 / 96 / 176.4 / 192 / 352.8 / 384 kHz のうち機器が対応するもの） |
| 24bit / 32bit float | 次のテイクと書き出しから。テイクのある曲でも変えられる（書き出しで 24bit / float に変換） |
| 曲と違う SR を選んだ | 「伴奏を 96 kHz にそろえています…」→「伴奏を 96 kHz にそろえました。96 kHz・32bit float で録ります」。その間は録音できない（理由を出す）。機器もその SR に切り替える |
| テイクのある曲で SR を変えた | 「この曲はテイクがあるので 48 kHz のまま録ります。96 kHz は次に開く曲から」 |
| 表示 | トップバーの SR・RECORD の形式（96kHz 32bit float MONO）・ステータスバーの EXPORT・書き出しダイアログの形式 |

![](screenshots/rec-format.png)

確認（Linux、PulseAudio の仮想デバイス、48 kHz の自作の伴奏）：
- 96 kHz・32bit float：テイクは float（WAV の形式 3）96 kHz、書き出しは 1920000 サンプル（20 秒ちょうど）の float
- 192 kHz・24bit：書き出しは 3840000 サンプル（20 秒ちょうど）
- 伴奏の変換（テスト）：48 → 96 / 192 / 384 kHz、44.1 ⇔ 48 / 88.2 kHz で 1 kHz の正弦波が理論値と 0.001 未満で一致（時刻のずれなし）。
  96 → 48 kHz では 30 kHz の音を -40 dB 以下に消す（折り返さない）

## スキン（DESIGN 4.11）

色トークン 16 個だけを着せ替える（書体・寸法・配置・動きは同じ）。内蔵 10 種＋自作（アプリ設定と同じフォルダの `Skins/` に `.vbskin`）。選んだスキンはアプリ設定の `skin`（無い・消えた時は booth）。

| 画面 | 内容 |
|---|---|
| 設定の「スキン」 | プルダウン（内蔵は「Booth — 夜のブース」のように英語名＋副題、自作は「名前 — 作者」/「自作」）。選ぶとその場で画面を作り直して設定を開き直す・保存。「新しく作る」でテンプレートから作る、「編集」でいまのスキンをエディタで開く。録音中はどれも押せない |
| テンプレートから作る | 内蔵 10 種と自作スキンを縮図（そのスキンの色で描いた小さなメイン画面）で並べる。いまのスキンに LED と「使用中」。選ぶとその 16 色を出発点にエディタを開く。キャンセルで設定に戻る |
| スキンエディタ | 画面の右に出る（背景は暗くしない。後ろの画面がそのまま見本）。名前・作者（64 文字まで）、テンプレート（選び直すと 16 色を写す）、保存先または「テンプレートの 16 色から始めます」。16 色をグループ（背景 / 線 / 文字 / 意味の色）で並べ、色見本を押すと右の色の面と HEX で変えられる（その場で画面に反映） |

| 見やすさの点検 | 問題なければ「見づらいところは見つかりませんでした」。あればアンバーで「『文字』と『地』のコントラスト比 3.2（4.5 以上がおすすめ）」など（多ければ「ほか N 件」）。保存は止めない |

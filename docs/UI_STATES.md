## Phase A で決めた解釈

- お手本は許容帯（幅 = ±ピッチ許容、既定 30 cent）。帯を外れて ±50 cent まではアンバー、超えたらコーラル赤
- 信頼度 0.5 未満の点、および 15 ms 以上の欠落は線を切る（嘘でつながない）
- 自分の線は再生ヘッドまで（歌ったところだけ）
- テンポ / キーの数値は右ラックに集約
- モニターリバーブはモニターミックスの 1 チャンネル（「耳のみ」、M/S なし）
- 録音中の赤はキャンバスの縁・タリー・再生ヘッド・録音中の区間だけ（画面全体は赤くしない）
- 起動時は停止状態（0:39）。`--play` で動く
- ウィンドウ最小 1280x800
- 再生・録音の時計は見た目だけ（音声デバイスは開かない）

## オフボの再生（B2）

曲を開いていて出力デバイスがあるとき、再生・シーク・ループは鳴っている音そのもの（再生ヘッドは音の位置から取る）。曲を開いていない（デモ表示）・出力デバイスが無いときは、従来どおり見た目の時計で動く。

| 操作 | 結果 |
|---|---|
| 再生キー / Space | オフボを再生・一時停止。曲の終わりで止まる（終わりで押すと頭から） |
| 停止キー | 止める（位置はそのまま） |
| 頭へキー | 頭へ（ループ中は範囲の頭へ） |
| 全体表示・レーンをクリック | その位置へ（再生中でも途切れずに飛ぶ） |
| レーンをドラッグ / `[` `]` | 範囲。ループ（`L`）が点いていれば範囲の終わりで頭へ戻る（すき間・重なりなし） |
| モニターの「オフボ」フェーダー | 音量（75 = 0 dB、100 = +6 dB、0 = 無音。急に変えず 20 ms でなめらかに） |
| 「オフボ」の M | ミュート |

| ステータスバー（右端） | 意味 |
|---|---|
| OUTPUT デバイス名 / kHz / バッファ | 開いている出力デバイス。曲を開くと SR を曲に合わせる |
| SR 変換して再生中 | デバイスが曲の SR に切り替えられないとき（試聴用に変換。DESIGN 13） |
| 出力デバイスを開けません：理由 | デバイスが無い・使われている等。画面はそのまま使える |
| UI MOCK | `-DVOICEBOOTH_UI_MOCK=ON` のビルド（音声デバイスを一切開かない） |

まだ無いもの：テンポ / キー（B11）、クリック・カウントイン、ほかのフェーダー（お手本・自分・リバーブ）、モニター・録音（B4〜）。

## デバイスと入力メーター（B3）

起動すると前回のデバイス（アプリ設定の `audioDevice`。戻せなければ既定）を開く。入力は 1 ch だけ（モノラル、既定 L）を開いてメーターに通す。入力の音は出力に流さない（モニターは B4）、録らない（B5）。

| 場所 | 表示 |
|---|---|
| ラックの INPUT | 機器名 — チャンネル（2 ch の機器は L / R）、ドライバとバッファ、LED メーター（ピーク・RMS・ホールド・クリップ）、PEAK / RMS の数値、適正 / 調整、LATENCY「… ms / … smp（申告値）」 |
| ステータスバー | 小さいメーター（クリックでクリップを消す）、ピーク dBFS、LATENCY「… ms（申告値）」、DRIVER |
| トップバーの入力デバイス | 機器名 — チャンネル。入力が無ければ「入力なし」（警告色） |
| 入力セットアップ 1 デバイス | 入力 / 出力の一覧（クリックで切り替え、多ければホイールで送る。名前が Bluetooth らしければ「遅延が大きい」）、DRIVER（2 種以上ならプルダウン）、CHANNEL（L / R など。1 ch の機器はモノラル）、SAMPLE RATE（いま / 対応）、BUFFER（プロはプルダウン、ほかは自動）、LATENCY（デバイスの申告値。実測ではないと明記）、MIC ACCESS（入力の状態）、切り替えに失敗した理由 |
| 入力セットアップ 2 レベル | 実メーター。判定はホールド（1.5 秒の最大）で：-3 dBFS 超「大きすぎます」/ -20 dBFS 未満「小さすぎます」/ それ以外 OK |
| 入力セットアップが自動で開く（B13） | 曲を開いた時、入力の機器（ドライバ | 名前）がセットアップを済ませた機器と違う（初回・機器を替えた）。起動画面・ほかのダイアログを閉じてから、止まっている時に開く。一度開いたら、同じ機器ではもう出ない |
| DRIVER に ASIO（Windows、B13） | ASIO を入れたビルド（既定）では ASIO のドライバが選べる。入れていないビルドだけ「ASIO は SDK のあるビルドのみ」 |
| 入力セットアップ 3 レイテンシ | 「REPORTED BY DEVICE」としてデバイスの申告値（入力 + 出力）。測定キーは押せない（実測と録音位置の補正は B6） |

メーター：ピークは下がる時 20 dB/秒、ホールドは 1.5 秒保ってから 20 dB/秒、RMS は直近 300 ms、クリップは -0.1 dBFS 以上が 1 サンプルでもあれば点灯し、クリックするまで残る。表示は 30 Hz。

| ステータスバー（右端の札） | 意味 |
|---|---|
| マイクの許可がありません | Mac で許可されていない。入力セットアップの「次へ」が押せない（DESIGN 13）。システム設定で許可してから開き直す |
| マイクの許可を確認中 | Mac の許可ダイアログに答え待ち |
| 入力デバイスがありません | 入力の機器が無い |

## 自分の声のモニター（B4）

入力（1 ch）を出力の L / R に同じ量で返す。曲が止まっていても入力があれば鳴る。録音はまだしない（B5）。

| 場所 | 動き |
|---|---|
| モニターの「自分」フェーダー | 返す量（75 = 0 dB、オフボと同じ目盛り）。横のメーターは耳に返っている量（入力のピーク＋フェーダー、-48〜0 dBFS） |
| 「自分」の M | 返さない。インターフェースのダイレクトモニターで聞く時はこちら |
| モニターの「リバーブ」フェーダー | 耳だけに掛けるリバーブ（小さめの部屋）の量。送りは「自分」のフェーダーの後。録音には入らない（DESIGN 4.7 / 14） |
| モニターの下の知らせ（スピーカー） | 出力の機器名がスピーカーらしい（`looksLikeSpeakers`：speaker / スピーカー / 扬声器 / 揚聲器 / 스피커、ヘッドホンの語があれば除く）時、その機器に替わった最初だけ「自分」を M にして理由を出す（アンバー）。M を外して鳴らしている間は「ハウリングに注意」（コーラル） |
| モニターの下の知らせ（遅れ） | 入力が開いていて「自分」を返している時、デバイスの申告の往復が 40 ms を超えたら「約 N ms 遅れて聞こえます。バッファを小さく／インターフェースで直接」（アンバー）。実測は B6 |

音の決まり：「自分」の分（リバーブ込み）は ±1 に収める（ハウリング・大声で耳を傷めないための最後の砦。オフボには掛けない）。音量・ミュート・リバーブ量は 20〜50 ms でなめらかに変わる。

![](screenshots/b4-monitor.png)

確認（Linux、PulseAudio の仮想デバイス 2 つ：入力用・出力用。入力に 441 Hz -12 dBFS を流して出力を録る）：
- 「自分」0 dB・リバーブ 0：出力 L / R とも -12.00 dBFS、止めた後は何も残らない
- 既定（「自分」64 = -2.8 dB、リバーブ 25）：-14.8 dBFS 前後、止めた後に左右で違う残響（50 ms 後 -34 dBFS → 1 秒後 -75 dBFS）
- 「自分」の M：出力は無音、遅れの知らせも消える

## 録音形式（SR・ビット数。2026-10-01）

入力セットアップ 1 デバイスの「REC FORMAT」行。標準・プロで選べる。簡単は「自動（曲に合わせる・24bit）」。選んだ形式はアプリ設定に保存。

| 場所 | 動き |
|---|---|
| SR のプルダウン | 「曲に合わせる（48 kHz）」と、この機器で録れる値（44.1 / 48 / 88.2 / 96 / 176.4 / 192 / 352.8 / 384 kHz のうち機器が対応するもの） |
| 24bit / 32bit float | 次のテイクと書き出しから。テイクのある曲でも変えられる（書き出しで 24bit / float に変換） |
| 機器が曲の SR で開けない（「曲に合わせる」の時） | 伴奏を機器の SR にそろえて「この機器は 44.1 kHz で開けないため、48 kHz で録ります（オケを 48 kHz に変換。元のファイルはそのまま、書き出しも 48 kHz）」。REC で止めない。テイクのある曲では変えない（従来どおり理由を出す） |
| 曲と違う SR を選んだ | 「伴奏を 96 kHz にそろえています…」→「伴奏を 96 kHz にそろえました。96 kHz・32bit float で録ります」。その間は録音できない（理由を出す）。機器もその SR に切り替える |
| テイクのある曲で SR を変えた | 「この曲はテイクがあるので 48 kHz のまま録ります。96 kHz は次に開く曲から」 |
| 表示 | トップバーの SR・RECORD の形式（96kHz 32bit float MONO）・ステータスバーの EXPORT・書き出しダイアログの形式 |
| 書き出しダイアログの 16bit / 24bit / 32bit float | その書き出しだけの形式（既定は録音形式の 24bit / float）。16bit は形式の欄に「（TPDF ディザー。無音の所は無音のまま）」 |

![](screenshots/rec-format.png)

確認（Linux、PulseAudio の仮想デバイス、48 kHz の自作の伴奏）：
- 96 kHz・32bit float：テイクは float（WAV の形式 3）96 kHz、書き出しは 1920000 サンプル（20 秒ちょうど）の float
- 192 kHz・24bit：書き出しは 3840000 サンプル（20 秒ちょうど）
- 伴奏の変換（テスト）：48 → 96 / 192 / 384 kHz、44.1 ⇔ 48 / 88.2 kHz で 1 kHz の正弦波が理論値と 0.001 未満で一致（時刻のずれなし）。
  96 → 48 kHz では 30 kHz の音を -40 dB 以下に消す（折り返さない）
- 機器が曲の SR で開けない（ローカルで機器の SR 切り替えを止めて再現）：44.1 kHz の曲を 48 kHz の機器で開くと、伴奏が 48 kHz にそろい、上のバー・書き出し・出力が 48 kHz、R で 24bit 48 kHz のテイクが録れた
- 16bit 書き出し：48 kHz の曲に -12 dBFS のトーンを録り、16bit で書き出し → 960000 サンプル・ピーク -12.00 dBFS・テイクの後ろは全部ちょうど 0。
  テスト：誤差 2 LSB 以内・平均の偏り 0.05 LSB 未満（JUCE の int 変換は切り捨てで 0.5 LSB 偏るので、整数は自分で丸めて渡す）・2 回書いて同じファイル

![](screenshots/export-16bit.png)

## 往復の遅れ（レイテンシ。B6）

入力セットアップの Step 3。録音位置の補正に使う値を測る・手で入れる。

| 場所 | 動き |
|---|---|
| 「測定する」 | 再生・録音を止めて、測定音（-12 dBFS のチャープ 5 回、約 4 秒）を出力に出す。その間ボタンは「測定中…」、右に「測定音を鳴らしています…」（青） |
| 測れた | 「5 回中 5 回そろいました（ばらつき 0.10 ms）。次のテイクからこの値で補正します」（ライム）。値の箱は ROUND TRIP・ms・「N smp だけ前に補正」 |
| 測れない | アンバーで理由：届かない / 小さい・うるさい / そろわない（反響・Bluetooth）/ 機器が止まった。入力が割れていれば「マイクのゲインを下げてください」を足す |
| MANUAL（手入力） | ms を入れて Enter か「この値を使う」。実測より優先。「手入力をやめる」で実測（無ければ申告値）に戻る |
| 測る前 | 値の箱は REPORTED BY DEVICE（入力 + 出力の申告値）。この値で補正する |
| ラック・ステータスバー・Step 1 の LATENCY | 補正に使っている値。申告値は「（申告値）」、手入力は「（手入力）」、実測は値だけ |
| 録音 | テイクの頭を補正量だけ前に置く（録り終わりの知らせの範囲は曲の中だけ）。曲の終わりの後も補正量の分だけ録り足してから閉じる |

![](screenshots/b6-latency.png)

確認（Linux、PulseAudio の仮想デバイス。出力 → 入力を module-loopback でつないだ）：
- 測定：5 回中 5 回そろう（ばらつき 0.10〜0.12 ms）。ただしこのループバックは遅れ自体が時間とともに伸びる（84 → 160 ms、録音中は毎秒約 2 サンプル）
- 録音の直前に 7604 smp、直後に 7676 smp と測り、その間に 20 秒の曲を通しで録った（入力 = 出力そのもの）。生のテイクは曲から 7625〜7649 smp 遅れ、
  書き出し（補正 7604）は 21〜45 smp。補正はちょうど測った値の分で、残りはループバックの伸び。書き出しは 960000 サンプル（曲と同じ）、テイクのファイルは 960000 + 7604
- テスト：44.1 / 48 / 96 / 192 kHz で 0〜450 ms の遅れがサンプル単位で一致、逆相・強い反響・割れ・雑音だけ・揺れ、バッファ 256 の機器の模型で 3 ブロック + 37 サンプル

## 遡及録音（B7。DESIGN 6.3）

再生中、REC を押せば録れる状態（曲・入力・アーム・SR）なら、アームしたトラックの入力を裏で録っている（画面には出さない）。

| 操作 | 動き |
|---|---|
| 再生中に REC / R | 裏で録っていた分をそのままテイクにする（録音は途切れない）。押す直前 0.3 秒に声があれば、フレーズの頭（250 ms 以上の無音の直後）の 50 ms 手前から採用。声が無ければ押した所から |
| 止まっている所から REC | これまでどおり（その位置から再生と同時に録る） |
| REC を押さずに止める・ループで戻る | 裏で録った分は消す（戻った時は次の周からまた録る） |
| 録り終わりの知らせ | 範囲は採用した所から（例：4.0 秒で押して「0:03.721 - 0:08.053」） |

![](screenshots/b7-retro.png)

確認（Linux、PulseAudio の仮想デバイス）：再生と同時に「2 秒の無音 → 330 Hz を 3 秒」を入力に流し、声が入って約 0.23 秒後（曲の 4.0 秒付近）に R、8 秒で止めた。
採用は 3.721 秒から（声の出だし 3.776 秒の 55 ms 手前）、書き出しは 960000 サンプルで声の所だけ音。テイクのファイルは再生を始めた所からの 8.19 秒。
REC を押さずに再生して止めると `.retro-*.wav` は消える。

## 自分の声のピッチ（B8。DESIGN 7.3）

曲が鳴っている間、入力の音程をピッチレーンに描く（録音していなくても）。

| 場所 | 表示 |
|---|---|
| 自分の線 | 10 ms ごとの点を再生ヘッドまでつなぐ。信頼度 0.5 未満・15 ms 以上の切れ目では切る（嘘でつながない）。お手本が無い間（B9 の前）は白 |
| 今の音の点・鍵盤 | いちばん新しい点（遅れ + 検出の 0.04 秒 + 0.05 秒まで）を再生ヘッドに。左の鍵盤にその音名（例 G4） |
| ピアノロール | 左に鍵盤、背景は半音ごとの段（黒鍵の段は暗い）。お手本の音符の棒は段に揃い、棒に音名。いま歌っている音の鍵が緑、再生ヘッドのお手本の鍵が青で光る |
| 横のズーム | Ctrl / Cmd ＋ホイール・ピンチで拡大縮小（マウスの位置を中心、2 秒〜曲全体）、ホイールだけで横に送る。波形レーンも同じ。開いた時は頭から 15 秒。凡例の右に「Ctrl＋ホイールで拡大」（入り切る時だけ） |
| 歌い直し | 同じ所をもう一度歌うと、その分だけ新しい線に置き換わる |
| 入り・ビブラートの札 | 見本の値なので、実際の声では出さない（解析は B18） |

![](screenshots/b8-pitch.png)

確認（Linux、PulseAudio の仮想デバイス）：再生と同時に「2 秒の無音 → E4（330 Hz）1.5 秒 → G4（392 Hz、±40 セント 5.5 Hz の揺れ）」を入力に流した。
E4 は 64.02（+2 セント）の平らな線、G4 は揺れがそのまま描かれ、切り替わりに外れた点は無い（667 点のうち、信頼度 0.5 以上で E4〜G4 の外は 0）。

## お手本の音程（B9。DESIGN 7.1.1）

オフボ（カラオケ）を開いた後に、声入りの原曲を入れると、お手本の線を重ねる。

| 操作・場所 | 動き |
|---|---|
| ピッチレーン（お手本なし） | 「お手本のピッチはまだありません ― 声入りの原曲をここにドロップすると重ねます」 |
| 原曲をピッチレーンにドロップ（`--guide=` も） | 「お手本を解析しています：〇〇.wav」→ 裏で時間合わせと声の取り出し。その間ピッチレーンは「お手本を解析しています…」 |
| 重なった | 「お手本の音程を重ねました（原曲とオフボのずれ 1.25 秒）」。青い帯（±許容セント）と線 |
| 自分の線の色 | 同じ位置のお手本とのずれ：帯の中（既定 ±30 セント）ライム / ±50 セントまでアンバー / それ以上コーラル。お手本の無い所は白。プロはセント値 |
| オクターブ合わせ | 点いていればオクターブ違い（男女・裏声）は同じ音として比べる。切り替えるとすぐ色を付け直す |
| 引けない組 | 別のミックス・音質違い：分離を勧める（下の「ボーカル分離」）。キー違い：「オフボは原曲と +2 半音違うキーのようです…分離した声の線をカラオケのキーにずらして重ねます」と分離を勧め、できた線はその分ずらす。知らせ「カラオケは原曲 +2 のキーなので、線もその分ずらしています」。お手本の声は原曲のキーのままなので鳴らさない（モニターのお手本は無効）。分離モデルが無ければ理由だけ。合わない「原曲とオフボの時間が合いませんでした」は線を出さない |
| オフボを開いていない | 「先にオフボ（カラオケ）を開いてから、お手本（声入りの原曲）を入れてください」 |

![](screenshots/b9-guide.png)

確認（Linux、PulseAudio の仮想デバイス。素材は自作）：自作の伴奏をオフボにし、その伴奏 ×0.97 ＋ 自作の旋律 7 音を 1.25 秒後ろにずらした原曲を `--guide=` で入れた。
お手本の線は 7 音ともオフボの時間の正しい位置（2.0 秒の E4 から）に出た。再生しながら「3 音は合わせる・4 音目 +40 セント・5 音目 −80 セント・残りは合わせる」歌を入力に流すと、
ライム・ライム・ライム・アンバー・コーラル・ライム・ライムになった。

## 本番 / リハーサルと録り間違いの救済（2026-10-02）

| 状態 / 操作 | 動き |

| RECORD の切り替え | 「本番」/「リハーサル」（以前の「納品」/「練習」）。ステータスバーの REC TO は DRY / TAKE・REHEARSAL |

## お手本の声を聴く（2026-10-02）

- 原曲−カラオケ（B9）・分離（B16）で取り出した声を、エンジンの 5 本目の枠（`PlaybackCore::guideSlot`）で鳴らす。録ったトラックと同じ経路なので、練習のテンポ・キーも掛かる。オフボの SR と録音の SR が違えば裏でそろえる
- 音量はモニターの「お手本」フェーダー（`mainGain`）、M でミュート。S（ソロ）はオフボ・お手本のどちらか 1 つだけを鳴らし、録ったトラックも止める。もう一方の S を押すと入れ替わる
- 自分の S：自分の声だけを聴く（オフボ・お手本・録ったトラックを止める。`selfSolo`）。モニターの S は同時に 1 つ（オフボ・お手本・自分のどれかを押すと、ほかの S は消える）。
  自分の声（入力 → ヘッドホン）はオフボ・お手本の S では消さない（お手本だけを流して重ねて歌う時に自分が聞こえなくならない）。自分の量・M はそのまま。曲を開き直すと S は消える
- お手本が無い間は帯を薄くして触れない（ツールチップで理由）
- ハモリのお手本（2026-10-02）：お手本を分離した時、リードボーカルのモデル（BS-RoFormer karaoke）で元の音からリードだけを取り、
  「お手本 Main」はリード、「お手本 Harm」は声 − リード（6 本目の枠 `PlaybackCore::harmGuideSlot`）を鳴らす。量は `harmonyGain`、M・S・メーターも Main と同じ。
  S はモニターの S と同時に 1 つ（オフボ・お手本・ハモリ・自分）。ハモリのトラックを選ぶと、ピッチの線・判定・テイクの数値はハモリのお手本と比べる。
  ハモリがほとんど無い曲（ハモリの声のある点がメインの 3% 未満）は線を出さない（音は聴ける）。原曲 − カラオケで取ったお手本は、続けて原曲からリードだけを取り（リードのモデルを分離プロセスの --model に）、リードをオフボの時間に写して分ける。モデルが無い時は分けない（1 本のまま）

## クリック・カウントイン・モニターのメーター（2026-10-02。DESIGN 4.2 / 7.2）

ベータで隠していた輸送バーの「クリック」・COUNT と設定の「カウントイン」は、本物のアプリでも出して効くようにした。
音はどれも耳（出力）だけで、録音（入力の素の声）・書き出し（テイクから作る）には入らない。

| 操作 / 状態 | 動き |
|---|---|
| 輸送バーの「クリック」 | 曲のテンポ（BPM・拍子・1 小節目）で拍を鳴らす。拍の位置は目盛り・BAR.BEAT と同じ（`song::beatSample` と同じ丸め）。1 拍目は高く大きい音（1.6 kHz・頭 -6 dBFS）、ほかは 1.1 kHz・-10 dBFS、約 40 ms。6/8 は付点四分（1 小節 2 拍） |
| 練習のテンポ・キーを変えている | クリックは伸ばした伴奏の拍に合う（拍の間だけが伸び縮み）。音の高さはキーで変わらない（出力の側で、聞こえている曲の位置から作る） |
| テンポが分からない曲で「クリック」 | 入らない。知らせ「テンポが分からないので、クリックを鳴らせません。上の曲の情報で BPM を入れるか…」。ツールチップも同じ理由 |
| モニターの「クリック」フェーダー | クリックとカウントインの音量（0 dB = 0.75。既定 0.62）。横のメーターは実際に鳴った量。入り切りは輸送バーのキーなので M / S は無い |
| COUNT Off / 1 / 2（設定の「カウントイン（小節）」と同じ値） | 止まった所から REC した時に数える小節。鳴っている途中の REC（裏録り B7 を含む）では数えない |
| 通しの REC（COUNT 1 / 2） | 曲は止めたまま、クリックだけで数える。数え始めは今の位置の小節の 1 拍目から COUNT 小節前（今の位置が小節線ちょうどならちょうど COUNT 小節。小節線の 1/4 拍手前より後ろは次の小節とみなす）。数え終わった所から曲と録音が始まる（数えている間の声は録らない）。曲の頭からでも同じ（曲の頭より前を数える）。BAR.BEAT は数えている拍（20 小節目の頭からなら 19.1〜19.4。1 小節目より前は 0、-1 …） |
| 範囲の録り直し（COUNT 1 / 2） | 範囲の頭の小節の 1 拍目から COUNT 小節前の所から曲を鳴らし、範囲の頭まで拍を鳴らして数える（クリックが Off でも）。曲の頭より前にはみ出す分は、曲なしで数えてから曲の頭を鳴らす |
| 範囲の録り直し（COUNT Off） | 2 秒の助走（数えない。クリック On なら拍は鳴る） |
| テンポが分からないまま COUNT 1 / 2 で REC | 数えずに録り始める。知らせ「テンポが分からないので、カウントインなしで録り始めました…」（曲ごとに 1 度）。COUNT のツールチップも理由 |
| 練習のテンポで数える | 数える拍の間も練習のテンポで伸び縮みする（そのまま伴奏の拍につながる） |
| 数えている途中で停止 / REC を外す | 何も録れていないのでテイクは作らない（空のファイルは消す） |
| モニターのオフボ・お手本のメーター | エンジンがフェーダーの後（ミュート・ソロ込み）で測ったピーク。上がる時はすぐ、下がる時は 20 dB/秒（入力メーターと同じ）、-48〜0 dBFS を LED に並べる（自分の帯と同じ目盛り）。練習のテンポ・キーの間は Rubber Band に入れる側で測る（聞こえるより伸ばす遅れの分だけ早い） |
| 設定に保存 | COUNT（`countInBars`）・クリックの入り切り（`clickOn`）・クリックの音量（`clickLevel`）。クリックの入り切りは、テンポの分かる曲で鳴る |
| 見本（UI_MOCK） | 音は無い。メーターは見本の値（オフボ -18 dB・お手本 -23 dB・クリック -20 dB） |

実装：拍を数えて鳴らすのは `audio::Metronome`（出力 1 サンプルごとに「このサンプルで聞こえる曲の位置」をもらい、拍に届いたサンプルで音を立てる。
位置が戻った・飛んだら次の拍を探し直す。Off の間も拍は数える）。`audio::PlaybackCore::play (countIn, countClicksUntil)` が数える分（曲のサンプル）を
受け取り、その間は曲の位置を止めてクリックだけを出す。数え終わったブロックは曲を lead サンプル目から鳴らし（`Rendered::lead`）、
録音（`TakeRecorder`）・ピッチ（`PitchTracker`）には入力をそこから渡す。数え始めの位置は `song::countInStart`。
メーターは `audio::LevelFollower`（atomic 1 つ。ロック・確保なし）。テストは `tests/ClickTests.cpp`。

## 声域とおすすめのキー（2026-10-02。DESIGN 18.1）

- 練習モジュールの下の段：「声域を測る」（測った後は「声域 C3–G4」）と「おすすめのキー ±n」。おすすめは声域とお手本の両方がある時だけ出し、押すとそのキーにする（収まれば ✓ / ›、収まらなければ ⚠ とツールチップではみ出し）
- 声域ダイアログ：「測る」→ 3 秒の間、楽に出せるいちばん低い声（高い声）を伸ばす → 声のある点の中央値を半音に丸める。0.3 秒分より少なければ「声が取れません」。−/+ で半音ずつ直せる。測っている間は曲を止め、マイクの音程は曲の外の位置で取る（`PitchTracker::setFreeRun`。曲の線に入れない）。声は保存しない。声域は設定に保存
- お手本の広がり：80 ms 以上同じ音を伸ばしている点だけ、中央値 ±15 半音の中の 5% / 95%（分離の残り・オクターブ違いで言い過ぎない）
- キーの選び方（`analysis::suggestKey`）：はみ出しの合計 → 上下の偏り（収まらない時は上下に振り分ける）→ 元の高さ → 元のキーに近い → 下げる方。1 オクターブ下（上）で歌う方が合えばそれも出し、押すとオクターブ合わせを入れる



歌詞の機能はあまり使わないので、**既定では出さない**。設定の「歌詞：オン / オフ」（既定オフ。保存する）で歌詞レーンを出す。
オフの間は歌詞レーン・Enter のタップ合わせを出さない（起動画面の解析の「歌詞」の行は B17 の自動合わせの取りやめで無くした）。歌詞のファイル（.txt / .lrc）をウィンドウに落とした時・歌詞パッドで「使う」を押した時は自動でオンにする。
読み込んだ歌詞・時刻はプロジェクトに残る（消さない）。

## 録ったトラックの再生（B12。DESIGN 4.6 / 7.3）

| 操作 / 状態 | 動き |
|---|---|
| 再生 | 採用したテイク（Main / Double / Harm）を伴奏と一緒に鳴らす。音は書き出しと同じ（継ぎ目のクロスフェードも） |
| トラックカードの線をドラッグ | そのトラックのモニター量。0 dB（線の 3/4）で吸い付く。動かしている間は右上に「-3.2 dB」。ダブルクリックで 0 dB |
| M / S | M で鳴らさない。S があれば S のトラックだけ鳴らす（伴奏はオフボの M で） |
| REC 中 | 録っているトラックは鳴らさない（自分の声だけ）。ほかのトラックは鳴る（ハモリを録る時に Main を聞きながら） |
| テイク・採用区間が変わった | そのトラックだけ裏で作り直して差し替える |
| 練習のテンポ・キー | トラックも伴奏と同じ速さ・キーで鳴る |

確認（Linux、PulseAudio の仮想デバイス、自作の 128 BPM の曲の Main に 330 Hz のテイク）：オフボを M にして頭から鳴らすと、テイクの所だけ 330 Hz が出て、Main を M にすると無音。
Main を録っている間は Main の音は出ない（出力 0）。

## 練習用のテンポ・キー（B11。DESIGN 7.2）

| 操作 / 状態 | 動き |
|---|---|
| PRACTICE のテンポ（50〜150 %） | 伴奏の速さだけ変わる（音程は変わらない）。テンポが分かっていれば「いま 108.80 BPM」、分からなければ「練習用」。ダブルクリック / 100 で吸い付いて原速 |

## キャッシュの場所（設定。DESIGN 8）

- アプリ共通のキャッシュ：既定は `アプリのデータ/VoiceBooth/Cache`（Win は `%APPDATA%`、Mac は `~/Library/Application Support`、Linux は `~/.config`）。いま置く物は「原曲だけで始める」で作ったオフボ（`offvocal/`）だけ
- 設定の行：場所と大きさ（`~/…/Cache · 2.2 MB · 曲ごとのキャッシュ（各プロジェクトの Cache）は別`）/「開く」（Finder / エクスプローラーでフォルダを開く。無ければ作る）/「空にする」/「変更」（フォルダを選ぶ）
- 「変更」：選んだフォルダをそのまま使い、設定（`cacheFolder`）に保存。次に作る物から新しい場所に置く。今ある分は動かさず、「今までの分（2.2 MB）は元の場所（…）に残っています」と知らせる。書けないフォルダは選べない（知らせて変えない）
- 「空にする」：大きさを見せて確かめる（ConfirmDialog）。消すのはアプリが作るサブフォルダ（`offvocal/`）だけ。選んだフォルダのほかのファイル、曲ごとのキャッシュ（`<プロジェクト>/Cache/` の分離・歌詞用の声）、プロジェクトの曲・テイクは消さない。分離の途中は消さない。終わったら設定に戻る
- 分離の途中（オフボを作っている）は「変更」「空にする」を押せない

| グループの「テンプレート ▾」 | 「テンプレート（○○）に戻す」（同じ色なら押せない）と「ほかのテンプレートから借りる」：内蔵・自作の一覧（そのグループの色の並びを添える。いまと同じ色の行に LED）。選ぶとそのグループの色だけ写る |
| 見やすさの点検 | 問題なければ「見づらいところは見つかりませんでした」。あればアンバーで「『文字』と『地』のコントラスト比 3.2（4.5 以上がおすすめ）」など（多ければ「ほか N 件」）。保存は止めない |
| キー | 保存（自作に加えて選び、画面を作り直して設定に戻る）/ キャンセル（開く前の色に戻して設定に戻る。閉じる・Esc も色は戻す）/ 書き出し…・読み込み…（.vbskin、ファイル選択は非同期。結果や読めない理由を下に出す）/ 削除（自作を編集している時だけ。2 回押しで消える。使っていたスキンなら booth に戻る） |
